Swift: `FlairEditorEffects`, a new optional product of the root Swift package, makes Flair an effects provider for the Pixerate editors' Swift package. `controller.setEffectsProvider(FlairEffectProvider())` on a `PaintEditorController` gives it every Metal shader as effect paper, effect layers, fills and effect paint, described exactly as `flairEffects()` describes them (generated by the new `pnpm swift:meta`), so documents move between web and Swift editors. Filters, transitions, masks and CSS colours render as in the TypeScript adapter.

**Breaking for Swift apps:** the Swift package (root and `swift/`, and `flair export metal`'s manifest) now targets macOS 14 and iOS 17 (was macOS 12 and iOS 15), because the editor's package needs them and SwiftPM sets platforms per package.
