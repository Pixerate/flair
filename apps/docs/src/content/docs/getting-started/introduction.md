# Introduction to Flair

**Flair** is a modern, lightweight graphics and visual effects library for web applications. It provides:

- **WebGL2 Shader Effects**: 300+ fragment shaders running directly on GPU with declared controls, interactive pointer uniforms, audio reactivity, and scrolling integration.
- **Animated Vector Effects**: 140+ animated SVG graphics, shape morphing, text path animation, and 23 motion primitives.
- **Catalog of Ready-Made Looks**: Over 450 effects categorized and indexed for instant use.
- **UI-Agnostic, Agent-Ready Effect Editor**: Headless editor architecture with Model Context Protocol (MCP) tool bindings so AI coding agents can edit and author visual graphics autonomously.
- **Directing & Interchange**: Multi-shot scene direction with camera moves and export to Lottie, FCP7 XML, and CMX 3600 EDL.

## Why Flair?

Traditional web visual effects libraries either force bloated dependencies (Three.js, Pixi.js) or require hardcoded CSS animations that lack fine-grained uniform control.

Flair maintains **zero heavy runtime dependencies**, works natively with standard HTML5 canvases and SVGs, and provides an architectural boundary designed for pair programming with autonomous agents.
