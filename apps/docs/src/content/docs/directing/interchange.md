# Interchange & Exporters

Flair scenes can be rendered directly to popular NLE video editors and web vector formats:

- **Lottie**: Export vector animations for web and mobile runtimes.
- **Apple Motion & FCP7 XML**: Import multi-shot camera scenes into Final Cut Pro or DaVinci Resolve.
- **CMX 3600 EDL**: Timecode accurate edit decision lists.
- **Headless Node.js Export**: High-res MP4, WebM, and GIF rendering via `@pixerate/flair/node`.
