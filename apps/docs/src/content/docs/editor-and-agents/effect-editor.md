# Effect Editor

`@pixerate/flair/editor` exposes `EffectEditor`, a headless editor designed on `@pixerate/editor`'s command architecture.

- **Non-Destructive**: Full undo/redo stack.
- **Keyframe Tracks**: Animate any declared `@control` over time with easing curves.
- **UI-Independent**: Embed into React, Svelte, or run in headless Node scripts.
